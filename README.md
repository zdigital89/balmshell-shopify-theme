# Balmshell Shopify Theme Starter

This is a Shopify Online Store theme starter for Balmshell Beauty. It includes a branded shop landing page, collection pages, product page styling, assets, and a starter product CSV.

## Upload as ZIP
1. Zip the contents of this folder, not the parent folder.
2. In Shopify Admin, go to Online Store > Themes.
3. Choose Add theme > Upload zip file.
4. Upload balmshell-shopify-theme.zip.

## GitHub Connection
Connect a GitHub repository where this folder is the theme root. Shopify expects layout, templates, sections, snippets, assets, config, and locales at the root.

## Collections To Create In Shopify
Create these Shopify collections and use these exact handles:
- soaps
- shimmer-lotion-bars
- lip-balms

The shop links are /collections/all, /collections/soaps, /collections/shimmer-lotion-bars, and /collections/lip-balms.

## Products
Use products-balmshell-starter.csv as a content starter. Add product photos manually in Shopify Admin or upload them to Shopify Files first if using CSV image URLs.
